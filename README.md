An entry for the make.fun bounty [Make the AI judge relax](https://make.fun/bounty/ai-judge-relax-01):
a short text, written to relax the AI judge reading it, about a grandmother shelling peas into a tin bowl.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the text to `/output/entry.txt`, or to `MAKEFUN_OUTPUT_DIR` when set.
